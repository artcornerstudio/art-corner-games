# WF-04 · School / Youth Program

Owner: Instruction & Education Pod (17) · Priority default: P2 (safety items P0) · Status: READY FOR APPROVAL

**Trigger:** school, youth org, or community program inquiry (also Research-found opportunities).

## Steps
1. **Intake** (`SCH-<id>`): institution, contact & role; program goals; student ages & count; sessions & duration; on-site vs. studio; school's consent/photo policies; supervision provided by school?; budget process (PO? board approval?).
2. **Safety safeguard checklist — MANDATORY, before any proposal** (Safety Review 04):
   - [ ] School/guardian consent paperwork path defined
   - [ ] Adult supervision ratio confirmed in writing with the institution
   - [ ] No unsupervised one-on-one contact by design (room layout, schedule)
   - [ ] Photo/recording policy agreed in advance
   - [ ] Incident contact path named
   - [ ] Data: roster held by school where possible; ArtCorner holds only what delivery requires
   - *Decision:* any unchecked box → HOLD with a specific request list to the school. **No checklist, no program** (tested, A3).
3. **Curriculum** (pod): original, age-appropriate sessions mapped to the school's goals → youth-content checklist → Safety sign-off → **Jean approves curriculum**.
4. **Proposal** (Proposals): scope, schedule (capacity-checked), matrix pricing (school pricing always Jean-reviewed line by line) → Finance → Brand → QA → **Jean gate**.
5. **Agreement:** institutional contracts/MOUs = Jean gate; insurance/clearance requirements (e.g., PA background-check clearances for school work) surfaced to Jean as a compliance checklist item — **agents flag, Jean provides**.
6. **Delivery:** session tracker; attendance via school where possible; per-session notes.
7. **Closeout:** outcomes summary for the institution; student work handling per photo/consent policy; rebooking for next term; Analytics record.

## Fail-safes
- Direct minor contact without confirmed supervision → HOLD, escalate (tested, A3).
- School asks for student data collection beyond delivery needs → Safety FAIL.
- Program content drifting from approved curriculum → pod flags to Jean before session, not after.
