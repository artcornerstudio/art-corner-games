# WF-09 · Content Pipeline (social, email, website, media)

Owner: Content & Communications (14); Media Production (23b) for video · Priority default: P3 · Status: READY FOR APPROVAL; all publishing NEEDS CONNECTION or manual

**Trigger:** weekly calendar cycle; a shareable studio milestone (Jean-approved); launch needs from other workflows.

## Steps
1. **Plan:** rolling 4-week calendar; each item lists source fact (Truth Ledger / approved project record), pathway, audience, channel.
2. **Draft:** copy + approved asset reference + alt text + posting notes. Video → Media Production package path.
3. **Fact & consent screen:** client-related content → consent on file? (no → Jean gate or drop). Meta Sabian → Librarian canon check. Youth-facing → Safety checklist.
4. **Review chain:** Brand → QA → content queue (digest §7) → **Jean gate: publish** (per-item until Jean grants a scoped policy, e.g., "approved-calendar items may post as scheduled").
5. **Publish:** manual by Jean, or by policy once channels are connected — honestly labeled in every handoff.
6. **Log & learn:** published record (what, where, when); engagement data only if a real source exists (else "no data source connected"); Jean's edits logged to the feedback file → style calibration, never silent ledger/brand rewrites.

## Fail-safes
- No approved asset for a planned item → item slips; no unapproved art ships (tested via gate design).
- Trend-jacking suggestions using copyrighted audio/characters → Safety/Brand FAIL.
- Website copy drift from catalog facts → Librarian drift audit catches; correction package prepared.
